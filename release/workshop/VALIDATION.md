| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| WASAPI／44.1 kHz | 138.4 ms | 127.7 ms | 82.2 ms | 121.6 ms | 6.98 s | 19.6–39.5 ms |
| WASAPI／48 kHz | 142.4 ms | 124.7 ms | 118.0 ms | 87.1 ms | 7.02 s | 19.6–39.6 ms |
| WaveOut／44.1 kHz | 151.0 ms | 148.3 ms | 70.4 ms | 107.9 ms | 6.98 s | 19.5–39.6 ms |

`tests/native-output-timing.test.mjs` 默认跳过发声测试；显式设置进程变量 `DANGO_RUN_AUDIO_TIMING=1` 后运行。`DANGO_AUDIO_OUTPUT=wasapi|waveout` 可选择单独分支，不设置时测试两种。仅输出频率匹配和时序，不保存回采原始音频。

回采范围：歌词时基数值使用原生报告及后台同样的时基外推与合成标记比对，不包括游戏画面的渲染帧或真实歌曲歌词标注误差。未测实体扬声器传播、蓝牙、Voicemeeter、设备拔插。60 ms 是请求缓冲值，不能承诺所有声卡达到同一延迟。WASAPI 初始化失败回退由故障注入验证，未在真实不支持 WASAPI 的驱动上复现。此候选尚未线上发布。
