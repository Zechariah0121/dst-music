# 0.6.0-beta.3 验证状态

本文件记录测试候选的事实和待验收项，不代表发布验收已全部完成。

## beta.3 本地验证

- 当前源码已安装到本机；后台更新接口实际返回 `unpublished`，原生播放器连接正常，原有完整队列、当前曲目与暂停进度恢复一致。
- 后台、更新检查、本机操作、游戏请求和原生播放器共 57 项测试通过；controller、bridge、music_ui、music_screen、mod_entries 离线检查通过，HUD 7 项通过。这些不是游戏引擎内验收。
- 打包、完整包与凭据扫描 19 项单元测试通过；候选包实际构建完成，隐私扫描和 ZIP 摘要检查通过。

## 历史已观察到

- QQ 音乐手机扫码登录成功，私人歌单读取成功。一首已购买、235 秒的歌曲由原生播放器播放、暂停、拖动进度并恢复，用户实际听到声音。
- QQ 逐词歌词生成 42 行、355 个片段，封面和字形生成成功。部分手机端可播放的歌曲（例如 Outside）接口仍不返回播放地址，问题未解决。
- beta.1 已在真实游戏显示账号、封面和歌词，发现引擎 5 秒低速错误。beta.2 将慢请求改为后台任务配短轮询，相关回归已通过。
- beta.2 后台已在本机更新，真实 QQ 请求通过短轮询读取歌单；已购曲恢复暂停位置，搜索结果顺序有变化，未声称原搜索队列完全一致。
- 解压后的 beta.2 配套包在独立端口使用合成静音素材，通过 Windows 原生播放、暂停、跳转、二维码和游戏字体字形生成，并验证模拟工坊目录缓存删除后的资源恢复；未使用真实账号。这不是实际 Steam 订阅验收。
- Windows PowerShell 5.1 夹具覆盖一键安装、升级失败恢复、默认关闭的自启动、同名启动项保护及持有真实 PCM 缓存句柄时重复启动的路径检查。未改写当前电脑自启动配置；真实 Windows 登录触发仍待验收。

## beta.3 尚待验收

- 实机验收 HUD 生命周期缓存及账号隔离、后台刷新失败保留、封面复用与回收、按钮对比度、ESC 原生设置入口、目录窗口聚焦与提示、自动/手动更新检查和下载失败后的显式重试。上述新功能不宣称已实机通过。
- GitHub 仓库已建立，当前没有 beta.3 Release；发布后另行验证更新提示与实际发布状态。

- beta.3 尚未在真实游戏实测：连接重读、两源 UI 和切换、账号、封面、歌词、播放、设置及性能的最终效果仍需验收。不能将回归测试等同于游戏实测，也没有 FPS 提升的测量结果。
- 新版 Lua 已加载前需重载游戏一次；之后播放器在线时游戏内连接入口可重读配置。验证这一流程及首次一键安装、更新、回滚、自启动默认关闭/显式开启/关闭、停止后台。
- 本机仅有 `local_netease_music`，尚未验证真实工坊订阅、更新和 Steam UGC 文件映射；须在真实订阅环境检查资源生成与读取。
- 两来源主题和半透明高光需实机视觉验收；玻璃效果不是后处理模糊。QQ 曲目权限和接口差异不能由单首成功证明整个曲库可用。

历史版本的测试记录见项目 `release/VALIDATION.md`；历史证据不等于本候选的实机验收。后续改动后的最终打包检查及启动器回归以实际运行结果为准。
