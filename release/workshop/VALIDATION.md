# 0.6.0-beta.3 验证状态

本文件记录测试候选的事实和待验收项，不代表发布验收已全部完成。

## beta.3 本地验证

- 当前源码已安装到本机；后台更新接口实际返回 `unpublished`，原生播放器连接正常，原有完整队列、当前曲目与暂停进度恢复一致。
- 后台、更新检查、本机操作、游戏请求和原生播放器共 57 项测试通过；controller、bridge、music_ui、music_screen、mod_entries 离线检查通过，HUD 7 项通过。这些不是游戏引擎内验收。
- 打包、完整包与凭据扫描 19 项单元测试通过；候选包实际构建完成，隐私扫描和 ZIP 摘要检查通过。

- 解压 beta.3 配套包，在独立端口以合成素材通过 Windows 原生播放、暂停、seek、二维码和游戏字体字形生成，并验证模拟工坊目录的资源恢复；未使用真实账号，不能替代真实订阅验收。
- 打包前记录：GitHub main 分支 CI 三次成功，包含新 ESC 入口与封面修复的 [Actions 记录](https://github.com/Zechariah0121/dst-music/actions/runs/43492697531) 构建成功，发布步骤因 main 分支而跳过。标签触发发布流程在此记录时尚未运行；后续结果以仓库 Actions 和 Releases 为准。

## beta.3 游戏内观察

- 已重新启动游戏并检查最终 ESC 主菜单：新增的原生“音乐播放器”入口可打开音乐设置，关闭后返回 ESC 菜单；原系统设置页不再出现音乐按钮。当前同时包含 Insight Menu、皮肤兑换等共 11 个菜单项，截图中均在面板内且无重叠。此前连接页的重新连接显示成功。
- 首页关闭再开立即显示缓存列表和多数封面；下滑未见整片空白。一张网易云推荐封面曾缺失：公开原图为 5000×5000，超过后台 1600 万像素安全上限而被拒绝。现已部署后台修复：网易 p1–p4 CDN 新下载请求 512×512 缩略图，不改像素上限、QQ 行为或旧缓存索引；目标歌单生产 API 返回成功和资源，隔离真实转换及 game-assets 12 项测试通过。重启后的游戏首页已显示此前缺失的“Playlist|氛围感音乐”封面。
- QQ 和网易云主题切换可见绿色和粉色，按钮白字清晰；设置使用滚轮和拖条滚动至底部，裁剪可见正常。
- 打开模组目录创建了本地 Mod 的 Explorer 窗口；游戏遮挡时界面提示使用 Alt+Tab，尚未证实能强制前置。
- 更新页显示 0.6.0-beta.3 和 `unpublished`，手动检查从“检查中”恢复正常；这不等于已有 Release 或已验证定时检查。
