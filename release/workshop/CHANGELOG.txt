Fixed false multiple-Mod detection when Steam's registry path and libraryfolders.vdf use different capitalization or path separators. Library paths, game paths and final Mod candidates are now normalized and deduplicated case-insensitively. Distinct physical copies still require explicit selection.

Existing users: stop the player, copy the updated companion files into your existing player folder while keeping .state, then reconnect the Workshop Mod and start the player. For this path fix only, replacing Runtime-Paths.ps1 and Install-Mod.ps1 is sufficient. Workshop updates do not automatically update a companion player already extracted elsewhere.
