[h1]DangoMusic | Bring your favorite songs into the Constant[/h1]
[b]Client-only mod · 64-bit Windows 10/11[/b]
Bring NetEase Cloud Music and QQ Music into Don't Starve Together: choose songs, control playback and see floating lyrics in game. Your server and friends do not need this mod.

[h2]First-time setup: 5 steps[/h2]
[b]The companion is included in the Workshop download.[/b]
[list]
[*][b]1. Subscribe and wait for Steam to finish downloading.[/b] In DST, open Mods → Client Mods and enable 本机音乐播放器（网易云 / QQ 测试版） (Local Music Player).
[*][b]2. Open This PC and search for 3836261433.[/b]
Enter the number below in the search box at the top right, press Enter and wait for the search to finish:
[/list]
[code]3836261433[/code]
[b]Open the search results and find the mod folder containing 一键启动播放器.cmd (One-click Start Player).[/b] If several folders match, choose the one under steamapps\workshop\content\322330 in your Steam library.
[list]
[*][b]3. Double-click 一键启动播放器.cmd (One-click Start Player).[/b] Choose a folder, or click 使用默认目录 (Use Default Folder), then 解压并启动 (Extract and Start). Wait for the companion to start.
[*][b]4. Return to DST and click 音乐播放器 (Music Player) on the main menu.[/b] In a world, F8 also opens it. Choose NetEase or QQ Music at the bottom left, then click the account entry. Scan with that service's mobile app and confirm login.
[*][b]5. Choose a playlist or search for a song, then play.[/b] Keep the companion running while listening.
[/list]
Filenames above match the download. Run the Windows launcher first: subscribing, enabling the mod or pressing F8 does not start a companion that is not running.

[b]No search result? Try this alternative:[/b]
Right-click DST in your Steam library → Manage → Browse local files. Go up two folders to steamapps, then open workshop → content → 322330 → 3836261433:
[code]SteamLibrary\steamapps\workshop\content\322330\3836261433[/code]

[h2]How to start the player next time[/h2]
If the companion is not running, double-click the same 一键启动播放器.cmd. If it is already running, open the in-game player directly.
You can play, pause, resume and close the player panel from DST's main menu without entering a world. In a world, use F8 or ESC → 音乐播放器 (Music Player).
Windows startup is [b]off by default[/b]. Enable it through 自启动设置.cmd in the mod folder: check the option and save. Turn it off in the same window.
Closing DST pauses music; resume it manually when you return. To exit the companion completely, run windows-player\停止配套播放器.cmd.

[h2]After a Workshop update[/h2]
[list]
[*]Close DST and run windows-player\停止配套播放器.cmd to stop the old companion. For an old manual installation, run 停止播放器.cmd in its original folder.
[*]Wait for Steam to finish, then run 一键启动播放器.cmd in the mod root to start the new companion. Launch DST afterwards.
[/list]
Existing 0.6.0 one-click installations retain their folder, accounts and settings. Switching from an old manual installation may require signing in again. [b]Restarting only DST does not replace a running old companion.[/b]
Settings → 更新与帮助 (Updates and Help) can check companion versions. [b]Checking does not install updates.[/b] No extra GitHub download is needed for first-time setup.

[h2]What can it do?[/h2]
Sign in to NetEase and QQ Music separately. Browse playlists, search, manage the queue, seek, adjust volume and choose repeat modes. Switching the browsing source does not interrupt the current track.

[h2]Common questions[/h2]
[b]F8 opens the player, but the companion is offline?[/b]
Check step 3 first. Click the top-right companion status for connection help; inside a world, ESC → 音乐播放器 (Music Player) also opens it. A running companion automatically attempts to restore a missing connection file, and the game rereads its connection settings. A stopped companion still needs the Windows launcher. Use Alt+Tab if a folder window opens behind DST.

[b]The previously selected installation folder is unavailable?[/b]
First follow the update steps above to use the new launcher. Run 一键启动播放器.cmd again, choose an available folder in the recovery window, then click 解压并启动 (Extract and Start). If your original folder was on a removable drive, you can reconnect that drive instead. Cancelling keeps the old location record. A new folder cannot recover deleted account data or cache, so signing in again may be necessary.

[b]You confirmed the QR code, but login did not finish?[/b]
Temporary network or save failures receive a limited number of automatic retries. When 重试确认 (Retry Confirmation) appears, retry without immediately generating another QR code. Generate a new code when the old one expires or the service explicitly reports an expired login. For persistent issues, report the exact message, mod/companion versions and reproduction steps.

[b]Where are the program and cache stored?[/b]
In the folder chosen on first launch; later launches and updates reuse it. The default is:
[code]%LOCALAPPDATA%\Zcc\DST-Music\Workshop\3836261433[/code]
Do not enable an old local copy alongside this Workshop mod, or run old and new companions together.

[b]Why does a song play on my phone but not here?[/b]
Membership, licensing, regional and preview restrictions still apply. Some QQ tracks may not return a playable URL; search may also fail when the service's interface is temporarily unavailable.

[b]Can friends hear it? What about Mac or local files?[/b]
Playback is local: friends cannot see your lyrics or hear your music. Synchronized listening, local audio import and Mac/Linux are not supported yet.
