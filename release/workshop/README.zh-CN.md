# 云间音乐 · 工坊测试候选 0.6.0-beta.3

在《饥荒联机版》浏览网易云音乐和 QQ 音乐歌单、搜索和控制播放，显示封面与悬浮歌词。纯客户端模组，服务器和朋友无需安装。配套播放器及对应源码随工坊包提供；本版本仍需游戏内验收。

## 首次使用

需要 Windows 10/11 x64、Steam 版饥荒联机版、音频设备和网络，以及 Windows PowerShell 5.1 和 .NET Framework 4.7.2 或更新版本。

1. 订阅并等待 Steam 下载完成，打开本模组工坊目录，双击根目录 **一键启动播放器.cmd**。它会校验并解压随包播放器、连接当前 Mod 并启动后台。
2. 在客户端模组启用云间音乐，进入世界按 **F8**。如果游戏已经加载旧版 Lua，更新后需重载一次；按 **ESC → 音乐播放器**：在线时打开音乐设置，离线时进入连接页并重读连接，无需再次重启。
3. 在账号页选择网易云或 QQ 音乐，用对应手机 App 扫码确认登录。选择歌单或搜索歌曲。

以后可再次双击一键启动；也可运行根目录 **自启动设置.cmd**，勾选并保存后让播放器随 Windows 登录启动。首次默认关闭；可在同一设置中关闭。游戏不能从零直接启动本地程序，首次至少要双击一次。后台在线时可通过游戏内入口打开模组目录；若窗口被遮挡，可按 Alt+Tab 切换。结束后台可运行 `windows-player/停止配套播放器.cmd`，安装目录内也有停止入口。

通常订阅目录是 `Steam库/steamapps/workshop/content/322330/3836261433`，也可能是游戏目录 `mods/workshop-3836261433`。Steam 库中右键游戏 → 管理 → 浏览本地文件，可找到游戏目录及其上层 `steamapps`。

## 更新、账号与隐私

可手动检查更新；启动和每六小时的自动检查可关闭，检查不会自动安装。版本检查读取 [GitHub Releases](https://github.com/Zechariah0121/dst-music/releases)；工坊条目是访问入口，订阅内容由 Steam 更新。下载见 [GitHub Releases](https://github.com/Zechariah0121/dst-music/releases)。

一键版安装到 `%LOCALAPPDATA%\Zcc\DST-Music\Workshop\3836261433`，其不同版本共享 `.state`。旧手动版不会被覆盖或迁移；首次改用一键版可能需要重新扫码。若 17863 端口被旧后台占用，先用旧目录中的停止入口关闭它，再启动一键版。旧本地 Mod 不要与本工坊版同时启用。

网易云与 QQ 账号分别登录和保存；切换来源只改变浏览平台，不会中断另一来源正在播放的歌曲。登录状态和私人缓存保存在本机，请勿分享 `.state`、连接文件、私人缓存或未经检查的日志。

自启动仅在用户勾选并保存后写入当前 Windows 用户的 HKCU Run 项；取消勾选并保存即可关闭。卸载时先关闭自启动并停止后台，再停用、取消订阅及按需删除上述用户目录；不会改动世界存档。

## 功能与限制

- 可调整界面、歌词、显示入口、快捷键与空间音效。左上角按钮默认显示，可在设置中隐藏，隐藏后仍可使用快捷键。两来源使用统一布局和各自的主题色；玻璃效果是游戏内半透明分层高光，并非真正的背景模糊。
- 播放受平台账号、版权、地区、会员及试听限制；部分 QQ 歌曲即使手机能播放，接口也可能不返回播放地址，不能保证全曲库可播。
- 普通逐行歌词的逐词动画是估算；真实逐词同步需要来源提供对应时间戳。空间效果处理歌曲本身，不添加环境音轨。
- 不支持导入本地音频、跨玩家同步播放或 Mac/Linux。订阅本身不会启动后台。
