# 云间音乐 · 工坊使用说明

**配套后台随工坊一起下载，不用另下安装包，也不用手动解压 ZIP。** 适用于 Windows 10/11 64 位、Steam 版《饥荒联机版》。纯客户端模组，服务器和朋友无需安装。

## 第一次使用

1. 订阅并等待 Steam 下载完成，在饥荒 **模组 → 客户端模组** 中启用「本机音乐播放器（网易云 / QQ 测试版）」。
2. 打开安装饥荒的 Steam 库，找到 `steamapps\workshop\content\322330\3836261433`。
   不知道库位置时，在 Steam 右键饥荒联机版 → 管理 → 浏览本地文件，再向上两层到 `steamapps`，依次打开 `workshop → content → 322330 → 3836261433`。少数安装在游戏目录的 `mods\workshop-3836261433`。
3. 双击根目录 **一键启动播放器.cmd**。首次选择安装目录，或点「使用默认目录」，再点「解压并启动」。等待后台启动完成；取消则不安装、不启动。
4. 回到游戏，点击主菜单 **音乐播放器**，或进入世界后按 **F8**。在账号页选择网易云或 QQ 音乐，用对应手机 App 扫码并确认登录。
5. 选择歌单或搜索歌曲，点击播放。**听歌时配套后台需要保持运行。**

首次需要在 Windows 中双击启动入口。仅订阅、启用模组或按 F8，不会启动尚未运行的后台。

## 以后每天

玩之前双击同一个 **一键启动播放器.cmd**，在游戏主菜单打开播放器，或进入世界后按 F8。安装目录和登录状态保存在本机，通常不必再次扫码。主菜单里也能暂停、继续或关闭播放器面板，不必先进入世界。

默认**不随 Windows 启动**。需要自动启动时，运行模组目录的 **自启动设置.cmd**，勾选并保存；取消勾选并保存即可关闭。它只设置当前 Windows 用户的登录启动项。

关闭饥荒后音乐会暂停；再次进游戏可手动继续播放。需要完全退出后台时，运行 `windows-player\停止配套播放器.cmd`，安装目录也有停止入口。

## 工坊更新后

1. 关闭游戏，运行 `windows-player\停止配套播放器.cmd` 停止旧后台。旧手动版在原安装目录运行「停止播放器.cmd」。
2. 等 Steam 下载完成，再双击工坊模组根目录的 **一键启动播放器.cmd**，启动新版，然后进入游戏。

已有 0.6.0 一键版会沿用安装目录并保留账号和设置。旧手动版不会自动迁移，改用一键版可能需要重新扫码。**只重启游戏，不会替换仍在运行的旧后台。** 不要同时运行新旧后台，也不要同时启用旧本地 Mod 和本工坊版。

游戏内「设置 → 更新与帮助」可检查配套后台版本；检查不会自动安装。默认在后台启动时及每六小时检查，可在「音乐与环境」关闭。Mod 由 Steam 更新，版本记录见 [GitHub Releases](https://github.com/Zechariah0121/dst-music/releases)。首次安装无需额外去 GitHub 下载。

## 常见问题

**上次选择的播放器目录已不可用，怎么办？**

运行工坊目录的 **一键启动播放器.cmd**，在恢复窗口选择可用目录，再点「解压并启动」。如果是移动硬盘暂时断开，先接回磁盘也可以；取消恢复会保留原位置记录。新位置不能找回已删除或无法访问的旧账号、设置和缓存，可能需要重新扫码。重新安装可选择空文件夹，或本播放器原本使用的目录。

**扫码确认后仍让重新扫码？**

先按上方更新步骤启动新版后台。暂时的网络或保存错误会有限次重试；看到「重试确认」时可以直接重试，不必立即生成新二维码。二维码过期或平台明确提示登录失效时，再重新扫码。若持续失败，请提供界面提示文字，不要发送二维码、账号文件或 Cookie。

**F8 打开了，为什么显示后台离线？**

先确认已完成首次使用的第 3 步。离线时按 **ESC → 音乐播放器** 进入连接页，或点击播放器右上角的后台状态重新连接。后台在线时可通过游戏内入口打开模组目录；窗口被遮住可按 Alt+Tab 切换。仍有问题时，请提供模组／后台版本、提示文字、音源、歌曲和复现步骤。

**程序、账号和缓存在哪里？**

在首次选择的安装目录；默认是 `%LOCALAPPDATA%\Zcc\DST-Music\Workshop\3836261433`。后续启动、更新、停止和自启动沿用该位置。已有一键版继续使用原位置，不会自动搬家。

安装目录的 `versions` 保存程序，`.state` 保存账号、设置和缓存；不同程序版本共享数据。默认目录另存 `install-location.json` 位置记录；游戏需要的封面与歌词纹理仍会同步到 Mod 资源目录。网易云和 QQ 分别保存登录，切换浏览来源不会打断当前歌曲。请勿公开登录凭据、`.state`、连接文件、私人缓存或未经检查的日志。

**手机能听，游戏里却播不了？**

平台会员、版权、地区和试听限制仍按账号权限执行；部分 QQ 歌曲可能无法获取播放地址，不能保证全曲库可播。普通逐行歌词的逐词动画是估算，准确同步需要歌曲提供逐词时间戳。

**队友能听到吗？支持 Mac、本地歌曲吗？**

目前只在本机播放，队友看不到你的悬浮歌词，也听不到音乐。暂不支持一起听、本地音频导入和 Mac/Linux。

**歌词、按钮和音效怎么调？**

在游戏内设置调整界面、歌词颜色／大小／位置／动画、快捷键和空间效果。左上角「音乐」按钮可隐藏，之后仍可用快捷键进入。空间效果处理歌曲本身，不添加环境音轨。音频默认使用 WASAPI 共享模式，初始化失败时回退到 WaveOut；运行中拔出设备可能导致播放失败。

**怎样卸载？**

先关闭自启动并停止后台，再停用和取消订阅；按需删除所选安装目录及默认目录中的位置记录。删除安装目录会同时删除其中的账号、设置和缓存，不会改动世界存档。
