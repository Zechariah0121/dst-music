[h1]DangoMusic｜把喜欢的歌带进永恒领域[/h1]
[b]纯客户端模组 · Windows 10/11 64 位[/b]
把网易云音乐和 QQ 音乐带进《饥荒联机版》，在游戏里选歌、控制播放、看悬浮歌词。服务器和队友无需安装。

[h2]第一次使用：照着这 5 步做[/h2]
[b]配套后台已包含在工坊下载里。[/b]
[list]
[*][b]1. 订阅本模组，等 Steam 下载完成。[/b]打开饥荒，在「模组 → 客户端模组」中启用「本机音乐播放器（网易云 / QQ 测试版）」。
[*][b]2. 打开「此电脑」，直接搜索 3836261433。[/b]
在右上角搜索框输入下面的数字，按回车并等待搜索完成：
[/list]
[code]3836261433[/code]
[b]打开搜索结果，找到里面有「一键启动播放器.cmd」的模组文件夹。[/b]如果有多个同名结果，选择 Steam 库下 steamapps\workshop\content\322330 中的那个。
[list]
[*][b]3. 双击「一键启动播放器.cmd」。[/b]第一次选择安装目录，或点击「使用默认目录」，再点「解压并启动」。等待后台启动完成。
[*][b]4. 回到游戏，点击主菜单的「音乐播放器」。[/b]进入世界后也可以按 F8 打开。在左下角选择网易云或 QQ 音乐，再点击账号入口，用对应手机 App 扫码并确认登录。
[*][b]5. 选择歌单或搜索歌曲，点击播放。[/b]听歌时配套后台需要保持运行。
[/list]
首次需要在 Windows 中双击启动入口；仅订阅、启用模组或按 F8，不会启动尚未运行的后台。

[b]搜索不到？用这个备用方法：[/b]
Steam 库中右键「饥荒联机版」→ 管理 → 浏览本地文件，向上两层到 steamapps，再依次打开 workshop → content → 322330 → 3836261433。完整路径是：
[code]Steam库\steamapps\workshop\content\322330\3836261433[/code]

[h2]以后每天怎么启用？[/h2]
后台没有运行时，先双击同一个「一键启动播放器.cmd」；已经运行就直接打开游戏里的播放器。
主菜单里就能播放、暂停、继续和关闭面板，不必先进入世界；进入世界后可用 F8 或 ESC →「音乐播放器」打开。
后台默认[b]不随 Windows 启动[/b]。想自动启动，可运行模组目录的「自启动设置.cmd」，勾选并保存；同处可关闭。
关掉饥荒后音乐会暂停，再进游戏可手动继续播放。需要完全退出后台时，运行 windows-player\停止配套播放器.cmd。

[h2]工坊更新后怎么做？[/h2]
[list]
[*]关闭游戏，运行 windows-player\停止配套播放器.cmd 停止旧后台。旧手动版请在原目录运行「停止播放器.cmd」。
[*]等 Steam 下载完成，再双击模组根目录的「一键启动播放器.cmd」，启动新版，然后进入游戏。
[/list]
已有 0.6.0 一键版沿用原安装目录并保留账号和设置；旧手动版改用一键版可能需要重新扫码。[b]只重启游戏，不会替换仍在运行的旧后台。[/b]
游戏内「设置 → 更新与帮助」可检查后台版本；[b]检查不会自动安装[/b]，首次安装无需额外去 GitHub 下载。

[h2]可以做什么？[/h2]
网易云和 QQ 音乐分别登录，支持歌单、搜索、播放队列、进度、音量与循环模式；切换浏览音源不会打断当前歌曲。

[h2]常见问题[/h2]
[b]F8 打开了，但显示后台离线？[/b]
先确认已完成第 3 步。点击播放器右上角的后台状态可以进入连接页；在世界内也可按 ESC →「音乐播放器」。后台仍在运行时，连接文件丢失会自动尝试恢复，游戏也会重新读取连接；后台已经关闭时，仍要运行 Windows 启动入口。文件夹窗口被游戏遮住时用 Alt+Tab 切换。

[b]提示「上次选择的播放器目录已不可用」？[/b]
请先按上面的更新步骤启动新版。再次双击「一键启动播放器.cmd」，在恢复窗口选择可用目录，再点「解压并启动」；若原来是移动硬盘，也可以先接回磁盘。取消会保留原位置记录。选择新目录不能找回已删除的账号和缓存，可能需要重新扫码。

[b]扫码确认后没有登录成功？[/b]
短暂的网络或保存错误会自动有限次重试；出现「重试确认」时可以直接重试，不必立即重新生成二维码。二维码过期或平台明确提示登录失效时，再重新扫码。仍有问题请提供提示文字、模组／后台版本和复现步骤。

[b]程序和缓存装在哪里？[/b]
在首次选择的目录，后续启动和更新沿用它。默认是：
[code]%LOCALAPPDATA%\Zcc\DST-Music\Workshop\3836261433[/code]
不要同时启用旧本地 Mod 和本工坊版，也不要同时运行新旧后台。

[b]手机能听，游戏里却播不了？[/b]
会员、版权、地区和试听限制仍按平台账号权限执行；部分 QQ 歌曲可能无法获取播放地址，搜索也可能因平台接口暂时不可用而失败。

[b]队友也能听见吗？支持 Mac 或本地歌曲吗？[/b]
目前仅本机播放，队友看不到你的歌词，听不到音乐；暂不支持一起听、本地音频导入和 Mac/Linux。
