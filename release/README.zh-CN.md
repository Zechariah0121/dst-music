# 饥荒里的网易云播放器 · 0.5.0

Windows x64 本地候选包。整体发布许可待作者确认，当前尚未对外发布；第三方组件保留原有署名与许可证。

游戏里浏览网易云歌单、搜索、扫码登录和控制播放，配有世界悬浮歌词、封面、歌曲卡片和动态岛。朋友和服务器不需要安装。后台使用本机原生音频，运行时不需要保留网页。

## 第一次使用

适用 Windows 10/11 64位、Steam 版《饥荒联机版》，需要联网和可用的 Windows 音频设备。包内已带 Node.js、Python 和 Pillow，不需要另外安装这些工具。系统需具有 Windows PowerShell 5.1、.NET Framework 4.7.2 或更新版本；Windows 精简版可能缺少这些系统组件。

1. 完整解压到自己有写入权限的文件夹，例如 `D:\Games\DST-Music`。不要在压缩包内直接运行。
2. 双击 **安装客户端Mod.cmd**。安装器自动查找 Steam 游戏目录，只向 `mods/local_netease_music` 安装，并为这台电脑生成独立的连接配置。
3. 双击 **启动播放器.cmd**，等待“原生音频已连接”。两个后台进程会保持运行。
4. 打开游戏，在“客户端模组”启用 **本机网易云音乐播放器**，进入世界按 **F8**。
5. 在播放器账号页开始登录，用手机网易云 App 扫码确认，然后打开歌单或搜索歌曲。

以后只需先启动播放器，再进入游戏。结束后双击 **停止播放器.cmd**。后台不能关闭后继续播放。

若无法唯一找到游戏目录，在解压目录打开 PowerShell，指定你自己的游戏路径：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Don't Starve Together"
```

只读环境检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Check-Environment.ps1
```

本包不会自动安装系统组件、更改系统代理或设置开机启动。

## 游戏内操作

- F8 打开/关闭面板；底部播放条支持暂停、上下首、拖动进度、音量、播放队列及循环模式。
- 设置页可调整歌词、字体颜色、辉光、逐词动画、歌曲卡片、动态岛和快捷键。
- “音乐与快捷键”中可分别启用各地区空间音效、雨天效果及总强度。月岛偏空灵宽阔，中庭尾音更深长，远古遗迹短而密，海上反射稀疏，桦树林较温暖短促。

## 更新和本机数据

安装前保存退出游戏。安装器会备份已有的本模组副本，更新后重启游戏加载新的 Lua 和图片。不要覆盖没有本模组标记的同名目录。

账号登录、偏好和本机凭据保存在包内 `.state`；私人的封面、二维码和歌词字库由本机生成，字体只读取你自己安装的游戏文件。**不要把使用后的整个文件夹发给别人，也不要分享 `.state` 或 `dangomusic_connection.lua`。** 对外测试应使用原始干净压缩包，并先完成发布许可确认。

移动解压目录前先停止播放器。移动后重新运行安装器，更新本机配置。重新解压到全新目录会使用新的登录与设置；当前播放队列暂不跨后台重启保存。

卸载时先停止播放器，在游戏中关闭本客户端模组，再移除本播放器文件夹和它安装的 `local_netease_music` 文件夹；无需修改世界存档。

## 当前边界

- 目前接入的是网易云在线账号歌单和搜索，不支持导入电脑上的离线音频文件、其他平台或“一起听”。会员、版权、地区和试听限制仍按账号权限执行。
- MP3 支持边下载边播。选新歌仍受获取链接、域名解析和首包网络速度影响；其他格式可能需要完整下载。拖到未缓冲的位置需要等待。
- 环境效果处理歌曲，不新增游戏环境音轨。地区约每1.5秒采样，未知模组区域按默认处理。音色为试听预设，强度与人声清晰度还需更多设备反馈。
- 世界歌词是投影到 HUD 的适配，不具备 MC 的完整3D遮挡或后处理 Bloom。普通 LRC 的逐词出现是动画推算，只有来源带逐字时间戳时才对应真实逐字时间。
- 生物舞蹈、自动 BPM、自动更新、手柄及所有分辨率组合尚未实现或完整验证。不能把本项目称为 DangoMusic 的官方移植或完全一比一还原。
