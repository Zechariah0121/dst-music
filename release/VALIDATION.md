# 验证范围

本候选与运行中的开发副本分开验收。不会把源码检查或替身测试称为所有电脑游戏实测。

## 已有0.5证据

- 后台、DNS、歌词解析和Windows原生播放45项回归通过。
- 慢速MP3数据未全部下载时可以播放；暂停回报约27ms是本机隔离夹具结果，不是任何网络上的选歌保证。
- 真实歌曲曾连续播放75秒并完整后台解码，随后正式后台的播放、暂停、seek均通过。
- DSP压力与固定内存缓存检查通过；更强预设的主观人声清晰度与沉浸感还需要玩家试听。

## 便携化证据

- 独立KTEX编码/解码测试、真实游戏字体冷编译、QR/封面、缓存/并发与路径防护检查通过。
- 三份DXT5字体解码与原ktech结果RGBA逐像素一致；中英字图像素与metadata一致；raw RGBA编码逐字节一致。
- Windows PowerShell 5.1在临时中文和空格路径验证首次安装、重复安装保留凭据、旧配置迁移、备份和路径保护。
- 使用包内Node 24.22.2、Python 3.13.17和Pillow 13.0.0重跑9项资源集成及4项KTEX测试，全部通过。
- 使用包内Node重新运行后台、DNS与歌词解析41项回归，通过。
- 实际ZIP解压到新的中文/空格路径后，Windows PowerShell 5.1环境检查通过，Node、Python/Pillow、.NET和NAudio均可加载。
- 从解压包运行后台和原生音频，使用随机本机端口、全新状态目录及合成静音素材，播放推进、暂停、seek、二维码和本机游戏字库编译均通过；未使用真实账号。
- 完整包安装到模拟游戏目录成功，并生成与开发副本不同的本机凭据。已有17863端口时启动器正确拒绝抢占，原有服务仍正常。
- 包内安装脚本的首次安装、重复安装、旧凭据迁移、用户文件备份、marker和junction防护夹具通过。构建器重读ZIP核验全部文件SHA-256与CRC，并扫描已知本机凭据；没有纳入私人状态和缓存。

## 未覆盖

其他人的电脑、Windows精简版、全部音频驱动、全部分辨率和模组组合尚未验证。便携资源编译器虽与旧产物逐像素一致，仍未重新完成独立游戏进程的全部视觉验收。Steam自动发现已根据注册表和libraryfolders实现，实际多人多库组合未穷举。为保留当前正在运行的播放器，没有在17863端口启动第二个生产实例；隔离原生播放使用同一包内代码和临时端口。
